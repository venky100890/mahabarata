# Kurukshetra Art Assets

This folder is the intended Unity import location for the v0.3 PNG HQ asset pack.

Expected structure after import:

```text
Assets/Art/Kurukshetra/ConceptBoards/
Assets/Art/Kurukshetra/Runtime/Characters/
Assets/Art/Kurukshetra/Runtime/UI/
Assets/Art/Kurukshetra/Runtime/VFX/
Assets/Art/Kurukshetra/Runtime/Buildings/
Assets/Art/Kurukshetra/Runtime/Environments/
Assets/Art/Kurukshetra/Runtime/SpriteSheets/
Assets/Art/Kurukshetra/Unity/Editor/
Assets/Art/Kurukshetra/Unity/Runtime/
```

Download and unzip `kurukshetra_png_hq_asset_pack_v0_3.zip`, then copy the included `Assets/Art/Kurukshetra/` folder over this folder.

See `Docs/Kurukshetra_v0_3_Unity_Asset_Import.md` for the full pipeline.
